## 사양
finish.sh와 check.sh가 이 블록을 읽는다(`VS_SPEC=treatment.md`). 키는 접두사 없이 쓴다. 아래 세 값은 기준 예제(templates/intro.src.html, 약 24.6초)의 값이다.
자기 영상에서는 `node "$V/scripts/render.mjs" intro.html --info`가 출력하는 줄로 바꾼다. 주석 처리한 줄은 기본값이다.
```spec
THUMB_START=12.6333   # 썸네일 시작(영상 초). 루프 시작을 프레임 경계로 올린 값
THUMB_END=20.6333     # 썸네일 끝. 시작 + 루프 한 주기(8초)
POSTER_T=16.232       # 본편 포스터 시각(헤드라인이 다 들어온 넓은 샷)
# THUMB_POSTER_T=     (기본: 썸네일 구간 가운데)
# W=1280
# H=720
# FPS=30
# MB_PER_MIN=8
# LUFS=-16
# TP_MAX=-1
# TW=1200
# TH=630
# THUMB_KB=400
# SEAM_XF=0           (0.3 이면 끝 0.3초를 시작 직전 프레임 쪽으로 섞는다)
```
