# Safety Guardrail

## When to use
다음 카테고리에 해당하는 작업 **직전** 자동 발동:
- DB 마이그레이션 / 스키마 변경
- 파일 대량 삭제 / 덮어쓰기
- 외부 API 호출 (결제·메일·Webhook)
- 권한·환경변수·인프라 변경
- 프로덕션 배포

## Process
1. 작업 내용과 영향 범위를 한 문단으로 요약.
2. dry-run 또는 diff 미리보기 실행.
3. 사용자에게 "진행할까요?" 확인 요청.
4. 승인받은 후에만 실행.

## Output format
```
⚠️  작업: [작업명]
영향 범위: [파일/테이블/서비스]
되돌리기 가능 여부: [가능/불가능]
dry-run 결과:
[출력]

진행할까요? (y/n)
```

## What NOT to do
- 승인 없이 실행
- 영향 범위를 과소평가
- "작은 변경이니 괜찮다"고 판단해서 스킵
